# Shared Task Board

This page is the human-readable task overview. The MCP bridge task list is the operational source for claims, status transitions, and agent coordination.

## Rules

- Create and claim tasks through MCP tools: `create_shared_task`, `list_shared_tasks`, `claim_shared_task`, and `update_shared_task`.
- Assign tasks to either `kilo` or `antigravity`; both are Full-Stack agents.
- Include acceptance criteria, dependencies, and exact file paths.
- One agent owns a task at a time. Avoid simultaneous edits to the same file.
- Keep this page as a concise project-level overview; do not manually duplicate every MCP task record here.
